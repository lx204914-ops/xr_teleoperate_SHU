## 模块并不是在每个场景都必要

| 实验 | 保存内容 | 可以说明什么 |
|---|---|---|
| C03七组 | [逐组结果](../numerical/data/C03七组机制消融.csv) | 完整19.09 s到达，关闭绕行40 s超时，说明特定瓶颈中有帮助 |
| 60场景×5组 | [300项配对表](data/300项配对消融.csv) | 完整57/60、关闭绕行58/60、固定半径60/60；不能声称完整方法到达率普遍更高 |
| 20场景×7组，200障碍 | [140项逐次](data/200障碍140项逐次结果.csv)、[汇总](data/200障碍分组汇总.csv) | 完整14/20，固定半径19/20；较大预留余量也可能挤压可行空间 |
| 三典型场景×五配置 | [15格表](data/15格典型消融.csv) | 比较动态半径、横向项、绕行和重选；不同终止口径不合并成功率 |
| 平滑变向及补充案例 | [420条表](data/平滑变向与补充场景.csv) | 其中400条为平滑变向，另有12条新增消融、4包围、4百障碍 |

动态预留边界被穿过与发生实体碰撞是不同事件。未到达运行的已执行路径，也不能作为“更短的完整通行路径”。

## 旧版与条件绕行版不能混写

[7500行联合表](data/original_and_conditional_7500.csv)包含旧版四方法6000条和新增条件绕行RA1500条。旧RA到达1264/1500，条件版1410/1500；三种基线复用，不能称为两批独立6000次。

原1000项任务为500场景×固定半径/关闭绕行两种消融，另复用旧主方法。其[原配对表](data/原1000项对应500场景配对.csv)中主方法429/500，后期[条件版对应表](data/条件版500场景配对.csv)为466/500，消融两列复用旧记录。因此这组表用于版本追溯，**不作为后期方法纯粹关闭模块后的配对证明**。原任务目录另有18项格式异常，本仓库不声称原始逐项记录全部完好。

用户已删除的600项完整批次只剩外部汇总，本次不将它作为主要复现材料。历史破损文件、恢复工具、重复图和未接受的候选分支没有发布。

## 结论边界

- Γ衡量当前方向容量，不保证全程可行或全局到达。
- 动态半径的收益主要需要由预留余量证明；不能把更大间隙直接说成效率更高。
- 6000次、一般消融、C03、RotorPy和PX4的版本、场景与停止口径分别记录。
- 现有材料支持部分工况下的通行收益与有限执行验证，不支持所有场景更优或真机保证。
