# 理论条件与主实验的覆盖范围

[返回首页](../README.md) · [版本与复现状态](版本与复现状态.md)

## 原保守单障碍选参条件

对于基本屏障约束，原区域充分条件采用

```math
a_{\mathrm{eff}}-2\omega_R^2\Delta R-\frac{(1+\gamma_\perp)^2S}{T_r^2}\ge0.
```

这里S是分析区域的净空上界， $`a_{\mathrm{eff}}=\min_\ell\bar u_\ell-a_{o,\max}`$ 。还需原定理的半径、横向速度、初始屏障等前提；不能仅检查这一条数值不等式。

代入[主数值实验冻结配置](../numerical/code/conditional_6000/current_method_conditional/method_config.json)： $`T_r=0.8`$ s、 $`\gamma_\perp=1`$ 、 $`\omega_R=0.1637582082`$ s⁻¹、 $`\Delta R=0.8587176690`$ m、轴向输入界2 m/s²、障碍加速度界0.8 m/s²，得

```math
2\omega_R^2\Delta R=0.0460560354\ \mathrm{m/s^2},\qquad S\le0.1846310343\ \mathrm m.
```

生成器的初始实体间隙至少0.75 m。初始化 $`R=R_0=r_{\mathrm{robot}}+r_o+0.15`$ m、 $`\dot R=0`$ ，所以屏障净空 $`s(0)=D-R\ge0.60`$ m。原统一充分条件的区域不能覆盖本批初始状态，因此不把6000次描述成由这条选参推论指导的覆盖验证。

## 怎样理解这个缺口

- 充分条件没有认证某状态，不等于该状态实际无安全输入；它给出的0.1846 m不是物理安全距离上限。
- 更远的状态反而可能超出该粗界，是因为它对整个 $`h\ge0`$ 区域内最不利的速度作统一估计。对给定状态保留实际余量，可能得到更好的判断。
- 单障碍各自存在输入，不能推出多障碍存在同一个共同输入。共同输入门禁、单障碍区域条件和整个周期的执行保证须分别检查。
- 本文档不以既有完成率替代定理前提；也不为满足粗界修改主实验参数或重跑原数据。

## 参数和执行口径

参考半径代码里的1.2 m/s²是冻结的制动设计参数。数值平台上它等于2−0.8；不能未经核对就把它当作所有飞控平台的有效控制能力。单个时刻的基本屏障约束、采样区间预留、实际跟踪误差预算是不同要求，本页不把当前可行性扩展为全程可行性、严格实时或全局到达保证。
