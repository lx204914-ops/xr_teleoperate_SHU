# 数值单例：输入和输出规则

[返回研究首页](../README.md) · [C03单例](code/c03/README.md)

本次只修复发布入口的配置路径、结果目录和场景标签。控制器、QP、参数与原统计不变。**没有用重跑单例替代历史结果。**

从`3d-ra-dpcbf`目录执行，只检查、不仿真：

```bash
python numerical/run_example.py --method ma_cbf_vo --scene numerical/scenes/ring10_actual.npz --out outputs/new_ma_case --check-only
```

- `--method`可选`ra`、`park`、`c3bf`、`ma_cbf_vo`。
- `--out`统一表示一个尚不存在的输出根目录；相对路径先按当前工作目录转换为绝对路径，四种方法完全相同。
- 实际结果位于`<out>/bounded/<输入文件名（不含扩展名）>/<方法变体>/`；已有输出根目录一律拒绝覆盖。
- MA始终从固定发布配置目录`numerical/code/conditional_6000/inputs/ma_settings.json`读取配置，在开始计算前验证，不再去输出目录找配置。
- `scene`标签取实际输入文件名（不含扩展名），不再写死为`corridor_crossing`。
- 默认只显示帮助。用户自行执行新单例时，才将`--check-only`改为`--run`；本轮没有执行这一操作。

检查模式只验证路径、JSON和保存的NPZ，不导入或运行控制器。基础设施测试用假后端验证四方法的实际输出绑定和拒绝覆盖；这不等于四个科学案例重新运行通过。

依赖版本见[复现说明](../reproducibility/README.md)。
